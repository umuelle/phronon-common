Our web server records standard access log entries: IP address, date and time, the resource requested, HTTP status, referrer and browser identifier. These logs are used solely to operate and secure the service, are not combined with other data, are not used to identify individuals or build profiles, and are rotated and deleted after {{ cfg.log_retention_days }} days. IP addresses processed for rate-limiting are held in memory only and never written to the database.
